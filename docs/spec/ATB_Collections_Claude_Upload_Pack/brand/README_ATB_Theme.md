# ATB Collections - visual theme for Claude

Apply this theme across all screens, including the dialer-connected agent desktop.

- Primary brand: purple #6F0BBB; brand yellow #F4C900.
- Navigation: deep purple #34035D; active row purple with a yellow marker.
- Main actions: yellow buttons with dark-purple text. Secondary actions and links: purple.
- Main workspace: white/light neutral; selected rows and tabs: pale lavender #F8F0FE.
- Keep green for successful/verified states, amber for warnings, red for critical/destructive states.
- Preserve text labels and accessible contrast. Never use white text on the yellow primary button.
- Use the original atb-logo.svg unchanged. Its own purple is #6F0BB5; do not normalize its paths to the UI purple.

The public ATB website stylesheet supplies the brand anchors. Neutral and status colours
are operational application choices, not asserted official brand-book specifications.
